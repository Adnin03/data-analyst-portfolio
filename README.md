## 🔍 Sorotan Proyek Terpilih (*Featured Case Study*)

### 01. 🏙️ [Jakarta Urban Air Quality & Mobility Analysis (2024)](https://github.com/Adnin03/jakarta-air-quality-mobility-analysis)
**Studi Kasus:** Menganalisis dinamika polusi udara (PM2.5, PM10, AQI), anomali cuaca ekstrem, dan dampaknya terhadap aktivitas masyarakat di DKI Jakarta sepanjang tahun 2024.

* **Data Sourcing & Pipeline**: Mengambil 8.784 titik data historis per jam (*hourly*) dari Open-Meteo REST API menggunakan skrip Python otomatis.
* **Temuan Utama (*Key Insights*)**:
  * **Nol Hari Kategori "Baik"**: 76,7% hari di tahun 2024 berada dalam kategori "Tidak Sehat" hingga "Sangat Berbahaya".
  * **Puncak Polusi Malam Hari**: Konsentrasi PM2.5 tertinggi terjadi pukul 23.00 WIB (85,7 µg/m³) akibat inversi suhu dan armada logistik berat.
  * **Mitos Akhir Pekan**: Polusi hari Minggu (64,4 µg/m³) sama beracunnya dengan hari Senin (64,8 µg/m³).
  * **Efek Curah Hujan**: Hujan lebat mereduksi partikel PM2.5 sebesar ~24%, namun konsentrasinya tetap 3,3 kali lipat di atas batas aman WHO harian.
* **Deliverable Utama**:
  * 🖥️ **Interactive Power BI Dashboard**: Dilengkapi 4 kartu KPI dinamis, formula DAX khusus, garis benchmark standar WHO (15 µg/m³), dan filter interaktif global (*Bulan, Tipe Hari, Musim*).

### 02. 🎮 [Steam Gaming Market Intelligence: Pricing & Player Loyalty](https://github.com/Adnin03/steam-market-intelligence)
**Studi Kasus:** Menganalisis 106,6 Juta ulasan gamer dan 4,7 Juta pemain simultan (CCU) pada 1.000 game terpopuler Steam untuk membedah strategi penetapan harga, paradoks Free-to-Play, serta dominasi studio independen vs penerbit raksasa.

* **Data Sourcing & Pipeline**: Ekstraksi 1.000 judul teratas dari SteamSpy REST API menggunakan skrip Python otomatis dan transformasi fitur analitik (*price tiers*, *positive rate*, *pricing type*).
* **Temuan Utama (*Key Insights*)**:
  * **The Indie Sweet-Spot ($10 – $19.99)**: Menghasilkan rata-rata kepuasan gamer tertinggi (88,8% ulasan positif).
  * **Paradoks Free-to-Play**: Menarik 2,5x lebih banyak pemain aktif (rata-rata 8.840 CCU), namun tingkat kepuasan anjlok hampir 10% (77,2% vs 87,0% pada game berbayar) akibat friksi mikrotransaksi dan review bombing.
  * **Pinalti Ekspektasi Game AAA ($40+)**: Game mahal mengalami penurunan kepuasan ke 82,9% akibat ekspektasi kualitas grafis dan gameplay yang sangat tinggi.
  * **Outlier Monopoli Ekosistem**: Valve Corporation memimpin pasar secara mutlak dengan 1,12M+ pemain serentak (24% dari total seluruh pemain aktif top 1.000).
* **Deliverable Utama**:
  * 🖥️ **Executive Power BI Dashboard**: Dilengkapi 4 kartu KPI terstandar, filter navigasi sidebar interaktif dengan tombol Reset berbasis Bookmark, dan layout 4-geometri (*Column, Bar, Table, Scatter Plot*).

## 🛠️ Metodologi Analisis Saya

Setiap proyek portofolio dalam katalog ini dikerjakan dengan standar industri:
1. **Business Problem First**: Mendefinisikan pertanyaan strategis dan siapa *stakeholder* pengambil keputusannya.
2. **Data Pipeline & Integrity**: Ekstraksi data mentah (API/SQL) dan pembersihan data dengan validasi tipe data yang ketat.
3. **Exploratory Data Analysis (EDA)**: Menguji hipotesis dan menemukan pola anomali dengan visualisasi yang jujur.
4. **Decision-Grade Dashboarding**: Membangun visualisasi interaktif yang mudah dipahami oleh eksekutif non-teknis.
5. **Actionable Recommendations**: Menyajikan minimal 2–3 langkah taktis konkret yang harus dilakukan bisnis.
